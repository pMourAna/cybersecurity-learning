# 🔐 Cybersecurity Learning 

## Sobre este repositório

Este repositório documenta minha jornada de aprendizado em Cybersecurity,
Networking, Pentest e Segurança da Informação.

Meu objetivo é construir uma base sólida em redes, sistemas e segurança,
desenvolvendo conhecimentos teóricos e práticos ao longo da minha formação.

## Objetivos 

- Construir uma base sólida em redes de computadores
- Aprender Linux e seus principais recursos
- Desenvolver conhecimentos em Cybersecurity
- Aprender fundamentos de Pentest
- Conhecer ferramentas utilizadas em segurança
- Praticar em laboratórios e ambientes autorizados
- Desenvolver projetos práticos
- Documentar minha evolução e meus aprendizados
